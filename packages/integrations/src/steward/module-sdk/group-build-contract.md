This build covers several modules (request.json modules), activated together after successful checks, with user confirmation only when required. Write each in its own subdirectory named after it; current/<module>/ holds each existing module's active version when the request was queued. When one module calls another with new arguments, change the callee's tool definition and its tests in the same build. Submit each with m_modules_propose and check it; when every declared module has a passing candidate (pending_review), call m_modules_request_group {versions: [{module, hash}, ...]} once, then read m_modules_check for each submitted hash and report the actual activation or pending approval outcome. Modules not declared cannot be submitted from this build.
