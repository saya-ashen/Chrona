# Code of Conduct

Chrona follows the Contributor Covenant Code of Conduct, version 2.1.

## Our standards

Expected behavior:

- Be respectful and constructive.
- Assume good intent, but accept corrections quickly.
- Keep critique focused on code, docs, design, and user impact.
- Be explicit about risks, tradeoffs, and evidence.

Unacceptable behavior:

- Harassment, insults, threats, or discriminatory language.
- Publishing private information without permission.
- Sharing secrets, tokens, private databases, logs with credentials, or exploit details in public issues.
- Sustained off-topic disruption.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, or other contributions that violate this policy. Repeated or severe violations may lead to temporary or permanent bans from project spaces.

Report conduct problems through GitHub repository contact channels. If the report involves a security issue, follow `SECURITY.md` instead.
