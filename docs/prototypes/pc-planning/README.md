# 配新电脑：内容优先参考页面（第二轮）

2026-09-17 · **待用户评议的设计参考，不是生产实现。**

用户反馈上一轮仍像面向专业人员的管理软件：希望像打开一个普通页面一样，立即知道在哪里看内容、在哪里写字、怎样切换页面。复杂功能保留，但按需打开。用户进一步给出场景：与 Agent 多轮确定大致配置、比较淘宝／京东购买路线，尚未决定何时购买，正在和父母商量。

本轮参考从这个场景出发。不是继续增加全局状态面板，也不意味着用户已批准新的生产导航、Schema 或文档编辑体系。

没有登录、API、Provider、真实邮件、商品跳转、订单、后台监控或浏览器持久存储。刷新后重置，或从顶栏「说明」中重置。第一轮 `workspace-experience` 原型保持原样，可对比。

## 这次想验证什么

**用户看到的是一份可以拿来商量、之后可以接着买的装机方案，不是采购流程控制台。**

1. **打开就是内容。** 无需经过概览／成果／版本／正文多层入口。
2. **页面导航是事情的名称。** 左侧首页、搜索、新建、配电脑／周末／读书等页面；手机从菜单打开同一组入口。
3. **日常语言表达近况。** “正在和家人商量购买时间”，不把等待家人当成阻塞、失败或待审批。
4. **细节渐进展开。** 四个主要部件默认可见，完整八项、理由、采购条件和历史按需打开。
5. **可以直接写。** 在方案下记笔记；新建页可直接输入标题与内容，不先选择任务类型。
6. **有意义的内容跨页一致。** 同一方案、采购路线、简版、笔记与首页共享这次预览的内存状态。

这只是一个内容组织参考。不能因此决定未来每种事情都硬编码一个专用页面，也不能把“页面可编辑”直接当成可以覆盖不可变的 Agent 成果版本。

## 可以点的内容

### 装机方案 `#computer`

- 完整配置：展开／收起八项部件。
- 为什么这样配：展示关键理由，而非逐轮聊天。
- 打开购买清单：按商店分组列出配件。
- 另一种买法：进入少拆单路线，不改变购买意向。
- 记下结果：直接定位并聚焦笔记输入区。
- 保存自己的笔记、修改最近一条；选择购买时间是显式操作，不从一句自由文本擅自推断。
- 记下“稍后购买”或“近期购买”只改变意向文案；不改配置、核价、通知或下单。

### 购买清单 `#computer/buy`

- 同一套配件在两条路线之间切换：两家示例店／一家示例店。
- 根据显示的逐项金额计算分组小计和总价。
- 商品信息按钮打开本地示例详情，不伪造真实商品链接。
- 优惠资格、完整型号、兼容性、售后和价格新鲜度保留核查入口。
- 明确只是已比较样例里的较低价，不声称全网最低或已验证可下单价。

### 给家人看的简版 `#computer/family`

- 用途、预算、为何不继续加配置、尚未确定的购买时间。
- 同步显示已保存的商量笔记。
- 选取文字供用户手动复制，**不读取或写入系统剪贴板，不自动发送或公开分享**。

### 之前的讨论与记录 `#computer/history`

- 需求、关键取舍、购买路线和用户自己的笔记有不同署名。
- 修改笔记不会抹掉此前的记录；不展开工具调用流水账。

### 首页、其他页面与新建

- 首页展示同一件事的近况，不用数字看板。
- 左侧／手机菜单直接切换页面，搜索按页面标题匹配。
- “周末去哪里”“读书清单”为可编辑的虚构笔记样例。
- 新建直接聚焦标题；首页一句话可以创建一个临时页面。
- 草稿在页面切换时保留，刷新失去；明确不是生产持久化。

## 样例数据边界

- 用户只给出了配电脑情境，没有提供真实用途、预算、型号或报价。本页 **2K 游戏、主机一万元、不含外设、不追求灯效** 都是用来画页面的假设，不能保存为用户真实偏好。
- 所有数值是人为构造的示例，不是平台查询结果。
- 八项分开购买：`2000 + 4200 + 550 + 700 + 900 + 160 + 450 + 300 = 9260`。
- 八项集中购买：`2100 + 4300 + 580 + 760 + 950 + 180 + 490 + 320 = 9680`。
- 运行时所有总价和差额由同一组 fixture 数字计算。没有实时价格趋势或自动刷新。
- 部件只是通用型号参考，不含真实品牌全型号、链接、店铺身份或 SKU。明确没有实查兼容性；不可照此采购。
- “家人商量结果”初始为空；没有编造父母已经同意、拒绝或提出某种具体意见。
- 用户自己的笔记不自动改写 Agent 整理的方案，也不授予外部操作权限。

## 文件

- `index.html`：静态入口、CSP、语义容器。
- `style.css`：内容型页面、桌面／平板／手机布局。
- `app.js`：虚构内容、导航、内存状态与交互。
- `checks.js`：可选浏览器交互检查，不随正常页面加载。

离线参考没有生产依赖。这些 HTML/CSS 帮助快速评议，不是另一套生产通用控件库；正式实现仍须用 shadcn、i18n、既有领域及权限契约。
