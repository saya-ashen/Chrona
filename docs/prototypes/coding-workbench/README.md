# 编码工作台交互原型

2026-11-08，根据工作台参考调研制作的第一版页面，供用户判断方向。它是独立的 HTML/CSS/JavaScript 示例，不接入 Chrona 或真实 Agent，不代表运行时能力和最终页面实现方式。

打开 `index.html`，或在此目录运行 `python3 -m http.server 4318 --bind 127.0.0.1` 后访问 `http://127.0.0.1:4318`。没有构建、网络字体、CDN 或其他依赖。刷新后恢复示例状态，不持久保存输入。

设计假设：可收起的工作列表，加一个主区；主区在交流和成果之间切换。默认不常驻终端、文件树或差异侧栏。色彩与形状参考仓库 DESIGN.md。

可试用：

- 切换三项示例工作，搜索列表，收起/展开列表。
- 给进行中的工作补充文字；展开执行细节。
- 在等待答复的工作中选择答案，继续同一工作。
- 请求停止，先显示待确认，约 4.5 秒后模拟确认停止。
- 查看成果及逐文件差异；对完成或已停止的工作接受成果，不提交或合并。
- 创建示例工作；用手机宽度切换工作和详情。

工作内容、代码差异和时间均为示例。停止后的继续执行、完成后的再次修订、真实附件与配置、成果版本切换尚未设计；输入区的对应限制仅用于使本原型状态自洽，不是最终产品规则。全局应用与设置图标仅显示说明。

验证：Chrome headless 检查创建、切换、问答、补充文本转义、停止两阶段、成果接受及手机列表导航；检查 390px、1024px 页面无横向溢出，并人工查看 1440px 和 390px 截图。截图：`preview.png`、`question.png`、`result.png`、`mobile.png`。未模拟真实手机软键盘。
