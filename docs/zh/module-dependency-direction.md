# 依赖方向

主仓依赖方向为 `apps → host → kernel → domain → contracts`；host 和 kernel 使用通用 SDK。数据库、运行配置、进程监督、Git workspace 和脱敏为必需基础能力，不存放具体应用业务。

具体应用依赖通用合同和 SDK，内核不导入应用源码、固定名单、页面、配置或构建器。新增应用通过普通安装与登记接入，不修改内核名单。应用私有数据由所属应用的有界工具提供，其他应用不能直接读库或文件。

应用之间通过绑定真实目标应用 ID、批准版本及合同的调用或回调交互。共享业务代码归各实际消费应用维护；复用本身不构成提升到 kernel 的理由。`uses` 只是声明；owner 权力来自当前批准版本显式 `authority: "owner"`，仍受精确审批约束。

具体业务登记、页面组合和通知渠道规则由所属应用定义。内核维护身份、授权、预算、幂等、持久唤醒、有限事实和停止证据；回调更换、同名重装和未知外部效果不能继承原绑定或自动重放。

当前代码地图见[架构](architecture.md)，公开目标见[API 规范](kernel-api-design.md)。早期内置应用名单、页面实验、生产转换和旧调用协议通过本文件 Git 历史查阅，不是当前运行指引。
