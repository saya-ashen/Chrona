# 应用迁出后的边界

2026-11-17 清理将具体应用实现、共享业务、页面、私有配置、应用测试、固定发行输入和生成恢复副本从主仓移出。应用源码、构建与验收由各独立仓库维护；主仓保留通用安装、登记、调用、审批、预算、生命周期、数据保护与停止证据。

不存在预装应用名单、首装免审批、按应用名暂停策略、特定 Provider 环境注入或入口环境变量桥接。空内核不要求 Provider、浏览器入口或通知应用才能启动。单一事实消费者由用户显式选择，未选中时保留事实。

应用通过通用 ModuleEntry 和 SDK 运行。HTTP listener 自行验证客户端身份，宿主透明转发应用的 Authorization、Cookie 与 Set-Cookie，并绑定内部传输 token；内核 API 另行鉴权。具体 Provider 自己加载私有后端配置，通过批准的通用能力取得凭据。

独立源码变更未构建、提交、发布或部署；主仓本轮仅编辑文件和静态核对，不声称通过测试。旧 13 应用适配、浏览器检查、固定发行和真实实例的记录仅证明当时版本，可从 Git 历史查阅。

源码归属见[独立应用](independent-applications.md)，依赖约束见[依赖方向](module-dependency-direction.md)，数据及恢复边界见[运维](operations.md)。
