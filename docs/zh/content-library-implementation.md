# 分类目录：本地实施记录（2026-09-18）

状态：**本地实现及最终回归完成；尚未部署或接入日常 Pi，用户可用性验收待反馈。**

## 用户确认的方向

不再以“我的页面”“最近的事”或少量常用条目作为主要入口。首页提供全部内容的
有组织访问。分类方式是一组互斥标签，界面表现为文件夹：每个内容在一组中最多
归入一个文件夹，可以同时属于不同组。各处打开同一内容，不复制 Task、成果、
笔记或日程。常用／最近只是未来可选增强，不代替目录。

例如“配一台新电脑”可以同时位于：

- 主题 → 设备数码
- 归属 → 家庭

## 已实现

- 首页／侧栏的分类组、文件夹、未分类、数量、搜索与分页。手机主区域同样可切换，
  不依赖隐藏侧栏。日程、待处理和更多高级功能保留。
- 用户创建分类方式、填写规则、控制 Agent 能否建文件夹；创建／重命名／删除文件夹。
  通过“调整分类”移动内容；未加入拖拽和任意层级文件树。
- 页面顶部显示已有归属，直接打开对应目录；整理记录默认折叠。
- 手动选择默认受保护，包括“保持未分类”。外部 Agent 不能覆盖或解除保护。
- Agent 读取现有方案与规则，复用已有文件夹或在获准组中创建缺少的文件夹；
  一次可原子归入多个组。返回实际归属及新增文件夹回执，技能要求明确告知用户。
- 改名保留稳定 ID；删文件夹只让该组归属变成未分类，不删除内容或其他组的归属。
- 并发冲突保留草稿，重新读取并对照后才能重新保存；未知结果保留原 UUID 和参数重试。
- 新内容先登记，再归类。归类失败不会重复登记；两项操作不是同一事务。

## 服务与安全

同一 Task 上增加分类关系，不另建内容系统。不伪造 Plan／Run，不启动 Provider。
五个新表位于唯一未发布迁移目录，已发布 SQL 保持不变；旧页面、笔记、成果、附件、
会议记录和授权不改写。迁移说明见 [Migration Release Lines](../en/migrations.md)。

新 `library:read`／`library:organize`／`library:configure` 权限分别控制读取、整理和
分类方案管理。旧凭据与 preset 不扩权；服务端事务内重新鉴权，执行工作区／分组归属、
revision、幂等与配额检查。默认关闭 `CHRONA_LIBRARY_WRITES_ENABLED`；关闭写入仍可读。
Owner 入口代表权限，不证明一定由人操作；技能禁止通过 Owner HTTP 绕过 MCP 限制。

开发过程中发现并修复：

- 事务帮助函数导入位置、SHA-256 前缀及 Bun 异步测试断言不匹配。

  保留单条回执不可删除约束并加入真实 SQLite 回归。
- Feature 导入未走 contracts 主公共入口，被依赖边界检查拦截；修正消费者，未放宽检查。
- Shell 单测的旧路由／HTTP mock 未覆盖目录，造成 5 项失败；补全真实契约形状，
  保留原日程和执行断言，增加目录控件断言。
- contracts 主入口达到行数阈值；紧凑整理既有导出，没有修改 lint 限额。
- 实际桌面截图发现英文侧栏按钮文字裁切、文件夹标题计数误用全库数量；修正并补断言。
- 全量旧 E2E 首次 157 通过／4 失败／16 跳过：语言切换 helper 过早选择导航控件、
  手机／平板断言误选面包屑而非主导航，已修正等待和定位，不放宽原高亮断言。
  另一次托管手动结果表单等待超时，执行源码和断言未改；原用例定向重跑通过，
  仍保留该次失败作为间歇性风险，不归因为已修好的执行引擎错误。
- 审查发现顶部“新建内容”与目录内按钮归类行为不一致；统一读取当前文件夹并冻结
  revision，分类冲突仍保留已创建内容。新增三尺寸用例同时验证顶部创建和部分成功恢复。
