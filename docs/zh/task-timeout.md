# 任务总时限

普通前台与后台任务默认不设总执行时限。全局设置中的“任务总超时（分钟）”留空表示不限时；填写 1–525600 的整数分钟数并保存后，后续启动的普通任务才会使用该值。清空并保存会恢复不限时。设置保存在工作区的 `runTimeoutMinutes`，未保存过该字段或值为 `null` 均表示不限时。

任务启动时确定本次截止时间。修改或清除设置不会追溯改变已运行任务，也不会复活之前已超时的任务。任务的读取、工具授权与用户停止仍按实际 Run 身份和状态检查；不限时不会绕过撤销、进程停止证据或执行容量限制。

内核在不限时任务中保存 `deadlineAt: null`、`leaseUntil: null`，通过 Agent 的私有启动合同将 `deadline: null` 传入 Pi。Pi 不安装总执行计时器，也不默认用模型静默五分钟来终止任务。用户配置的有限时限仍贯穿内核、Agent 与 Pi，并在超时时停止实际执行。

Provider 实际结束后，如果完成结果的数据库事务暂时失败，内核会保留原结果及停止证据，在后续 tick 重试保存；不依赖任务截止时间，也不重新执行任务。重试时仍以用户取消标记为准，缺少退出证据时继续报告停止未知。

本项是整个普通任务的总时限。单次工具、用户交互、模型补全请求的有界等待，以及显式带预算的执行或内部构建保持各自的合同；设置页明确注明只影响后续启动的前台与后台任务。取消或未知停止仍占用执行容量，直到获得实际停止证据。
