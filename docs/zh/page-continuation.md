# 页面反馈与 Agent 接续

本文记录实现契约及本地开发阶段验证。后续单实例授权部署记录见
[接入说明](../en/work-results-integration.md)；不代表公开发布或其他实例部署授权。

## 用户体验

用户照常保存备注、填写表单。需要 Agent 修改时展开「交给 Agent 继续处理」，写一句需求并保存，再复制接续说明到自己的 Agent。没有自动唤醒、排队或执行。页面显示最新请求、新增意见和 Agent 的更新说明；旧请求、旧表单和版本仍可追溯。

## 数据与权限

- 复用 `WorkPageInput`，新增不可变 `handoff` 类型；只能通过已有 owner 输入入口创建，不向 MCP 开放代替用户提交。
- 请求绑定当时的 headVersionId 和 inputRevision。快照包含该修订之前每条备注的最新值，以及该版本每份表单的最新回答；不是聊天记录，也不是权限授予。
- `page_read(view=handoff, requestId?)` 默认取最新请求，可指定旧请求；按页读取快照，携带原版本的表单定义。新增/修改的输入不会偷偷加入旧请求。保持读取权限、作用域和输出上限。
- Agent 通过已有成果发布入口提交可选 `continuation`：请求 ID、原版本 ID、更新摘要、变化清单、逐条反馈处理说明。所有输入引用必须来自请求快照。发布仍绑定当前结果修订；不得为了回应旧反馈覆盖新内容。
- 更新说明是作者报告，不是事实核验或用户验收。只将明确列出的反馈标为「作者称已采用」；未列出的仍未说明，延后/待澄清独立呈现。普通新版不会自动消除请求或反馈。
- 保护页面反馈元数据：读需 pages:read；新增/移除需 pages:read/write。旧成果凭据不扩大权限。重试重新检查权限、开关和任务状态。
- 请求不创建 Run、Plan、工作时段，不改任务状态、验收指针或 Goal，不购买、不发邮件、不授权任何外部操作。

## 兼容与验证

仅修改当前未发布迁移线的输入 guard；为已提交 baseline 注册 checksum-keyed amendment，保留全部旧数据和已发布 SQL。验证快照/分页、旧表单、跨作用域/未来引用、CAS/重试/撤权、关闭状态、隐私、无执行副作用及三种视口。

以下本地开发验证轮次不包含部署、线上凭据变更或本地 Agent skill 自动安装；
后续部署单独记录，不将本地测试等同于线上验收。
