# Provider 运行：复用 Pi，补齐宿主接线

Chrona 管事务、持久消息、队列/恢复、调度、自己通道的审批/预算与用户界面；Pi 管推理、文件/命令/网页工具、技能、扩展、MCP 与原生执行权限。不另建技能/MCP/模型执行器。

## 启动和显式资源

先按[运维说明](operations.md#确认-agent-真正可用)准备专用绝对命令、精确版本和私有 profile。默认 `0.85.0`；显式可选 `1.3.0`。不同版本的 MCP/扩展能力不等同，不自动升级，不复制个人认证。

默认继续关闭发现、模板、上下文文件、主题及项目信任。需要资源时，由 owner 设置 `CHRONA_STEWARD_PI_RESOURCES_FILE` 指向审核过的 JSON 文件，例如：

```json
{
  "skills": ["/opt/chrona/resources/research/SKILL.md"],
  "extensions": ["/opt/chrona/resources/web/index.ts"],
  "tools": ["web_search", "fetch_content"]
}
```

这是示例，不是已安装资源。文件须私有（Unix 建议 0600）、规范绝对路径、不经符号链接，位于 Pi profile 与事务树之外；单文件最多 32KB。技能是明确的 Markdown 文件；扩展是明确的本地入口文件，不接受包安装指令、URL、glob 或任意内置扩展。入口须为规范绝对文件、非 group/world 可写，同样不能来自 profile/事务树。空清单/未配置不会发现个人资源；错误清单使 Provider 不可用，不退回默认环境。修改清单后重启服务。

Pi 1.3 还可显式选择 `builtin:mcp`、`builtin:codemode`、`builtin:tool-search`。前者复用该专用 profile 的 Pi `mcp.json`；只允许 owner 明确批准的服务器/账户，**本次源码改动没有配置私人服务器、迁移 OAuth 或连接真实账户**。工具名也须列在 `tools`。例如只读假服务器工具名可为 `mcp__fixture__ping`，实际名称以 Pi 为准。`codemode` 或 `bash` 执行资源要求配置 bubblewrap，不能借清单绕过 bash 关闭规则。

启动后 `get_commands` 只接受显式选择的扩展/技能来源。网页执行详情显示已检查到的技能命令名、版本和显式扩展数；这不是完整工具注册表，也不证明每个工具已经成功执行。显式资源仍是受信代码：须审查入口、扩展及 profile 的权限/配置；只读宿主挂载和专用 profile 不是完整秘密隔离，原生 MCP 配置及授权仍由 Pi 环境负责。尤其不能把可写 profile 误称为 Agent 无法修改的配置边界。

## 完成、补充和停止

- 正常模型运行以会话级 `agent_settled` 为完成候选，再核对最新状态/消息队列/请求/注入 epoch；`agent_end` 不代表恢复完成。
- 补充消息用 Pi 原生 `prompt(streamingBehavior="steer")`，由 Pi 决定忙时排队、空闲时启动，不把已空闲后的消息只塞进队列。
- Pi 1.3 明确返回 `disposition=handled` 的无模型命令/输入处理器不等待不存在的模型结束事件，仍核对运行/UI状态。0.85 没有这一已文档化的 disposition 保证；不能用 1.3 元数据验收推断所有 0.85 扩展路径。
- 取消/超时先保留终止结局、拒绝迟到注入，`clear_queue` 成功后才 `abort`；失败则关闭/有界终止进程。最终文件提交等待子进程退出。
- owner 的“停止本次处理”具有持久取消标记，立即撤销该运行的 Chrona 工具能力；排队/准备启动/最终提交中的取消同样生效。本次不自动重试，已保存消息/文件不删除。不承诺撤回已经发生的外部副作用，不自动取消未来调度。
- 用户暂停/结束事务会停止当前及已排队处理。Provider 自己暂停事务的收尾工具豁免仍按既有策略生效，避免中途把它的最后一次说明误杀。

## 待答复请求

全局待答复区在今日、事务、材料页与设置页均可见；不因当前页面与运行归属不同而丢失确认入口。选择不预选答案，确认须明确是/否；空白文本不能误触发送。编辑器原文仅从存活 controller 临时提供，轮询不重置已经输入的修改，也不填入聊天框。原文和自由文本答复不存请求审计，不在重启后回放。

请求绑定 owner 工作区、运行和新的独立请求 id；选项用序号校验并在适配器中还原为原选项。重复答复只接收一次。timeout、运行 deadline、取消、暂停/结束、进程退出或重启会使旧请求失效，不能跨运行沿用。请求最长 5 分钟；这不是可跨日恢复的 Provider 原生权限会话。失败时可在事务中由用户明确继续，执行端需要重新请求授权。

敏感/过长上下文拒绝发布，不提供对隐藏细节的同意按钮。已知密钥、能力 token、常见凭据格式与控制字符被过滤；不能据此承诺识别所有未知秘密。UI 提醒不要输入密码/密钥，认证应走服务专用 Pi 配置流程。对话原文、工具参数/输出、thinking、原始 notify/widget、set_editor_text 不经这个通道转发；扩展不能借 UI 修改聊天草稿或绕过通知预算。

通知复用既有预算和送达，每次运行最多一个请求提示，失效时尚未发出的提示被抑制。静默时段/上限可能使提示只留网页或进汇总，不能声称 QQ 必达。API“已记录答复”不是 Pi/外部系统完成动作的回执；UI 子协议没有外部动作成功确认，网络/进程故障后的结果须如实核对。

## 进度、用量与持久化

安全进度只记录阶段与受限工具名，不存思考、参数、结果。事件有上限和去重，属于尽力而为的可观测性，不是完整执行录像。用量复用 `get_session_stats`；只有同一 session 且计数未回退时才计算本次增量，否则显示会话累计。缺失/超时统计保持未知，不伪造 0。金额是 Pi 的 USD 估算，不是账单，不把每日运行次数上限冒充金额预算。

当前用既有 Audit 追加技术事件、请求元数据与唯一答复回执，未改 schema/迁移。请求 controller 和原文/自由文本答复仅在内存；持久记录不会重放授权。旧请求没有存活 controller 时显示中断。

owner API（均须原有 owner 认证及 `workspaceId`）：

- `GET /api/steward/provider/runs?workspaceId=...&affairId=...`：最近运行、安全进度/统计/资源与请求。`affairId` 可省略；不是无界历史导出。
- `POST /api/steward/provider/interactions/:id/answer`：`{"decision":"submit","value":false}`；选择为整数序号，文本为字符串。关闭为 `{"decision":"cancel"}`。类型/选项不符 400，跨工作区 404，已失效/重复 409。
- `POST /api/steward/provider/runs/:id/cancel`：停止本次，不重试。

这些 API 不接受 Grant scope，不属于 `chrona_request_approval`，不能扩大 Chrona 的邮件发送、来源、购买等权限。Provider-owned tool 的风险还须由其运行环境/已审查扩展控制。

## 材料的查看与下载

附件字节通过原有 owner 认证读取，再转换为可撤销 Blob URL；不把 API key 放入链接，不给第三方图片/链接发送认证头。页面切换、重新加载和卸载会撤销旧预览 URL。下载也经鉴权，不靠放开 raw 接口来修复直链。

事务内 Markdown 相对链接在当前事务中导航，图片只加载目录内的受支持栅格图片；拒绝越界/元数据路径，远程 Markdown 图片不自动加载。音频/视频附件使用浏览器原生控件（无自动播放）；HTML、SVG、PDF 不嵌入执行，未知文件只下载。格式/编解码器不支持时显示失败并可下载。自定义反代 CSP 需单独核对图片/媒体的 `blob:`，不能因此放开脚本或 iframe。

这是文件使用闭环，不是录音、转写、音视频理解或生成引擎；这些工作仍由明确接入的 Provider 工具/模型处理，本轮未接入外部媒体服务。

## 验收边界

假 Provider 的三尺寸浏览器流程覆盖请求、编辑、拒绝、完成、取消和无横向溢出；真实 Pi 的离线元数据探针只使用空认证、合成技能/扩展/stdio MCP，不调用模型，不代表真实来源、OAuth、智能性、外部发送或跨日工作的验收。部署前仍须准备专用配置、备份/回滚，并由 owner 单独授权及执行真实场景验收。
