# 通用 Agent 与独立 Provider

文件名保留既有文档入口，Agent 不再是内置应用。公开 `agent` 命名空间属于通用内核；具体 Provider 是独立应用，主仓不携带适配器、默认应用名单或模型配置。

内核负责上下文与 Run 身份、固定工具目录、预算、排队、租约、取消、调用回执和实际停止证据。会话展示、聊天历史、提示词策略、记忆、交付和后端协议归应用。应用以实际批准版本登记执行能力，用户可以选择、停用或移除它，空内核也能启动。

具体 Provider 的进程使用通用宿主启动合同；内核不根据应用名注入模型凭据、不自动批准首装，也不为某个后端保留特殊环境入口。权限和停止证据与应用业务迁出分别处理，不能因删除适配器而删除内核守卫。

完整七工具目标、登记与调用合同见[API 规范](kernel-api-design.md)，当前代码地图见[架构](architecture.md)，通用进程接入见[Provider 边界](provider-runtime.md)。2026-11-17 清理仅完成源码和静态工作，旧测试与部署记录不能证明本轮改动可运行。
