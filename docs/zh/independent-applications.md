# 独立应用边界

Chrona 仓库只维护通用内核、宿主、CLI、数据库及 SDK。具体应用在独立 `chrona-module-*` 仓库维护，包含其业务源码、页面、配置、依赖、测试、构建及发行材料。主仓不携带应用 bundle、artifact、默认预装名单或 `.generated/applications` 副本。

会话、交付、分页和业务调用适配等此前 `packages/app-common` 内容归消费应用私有维护。主仓不通过复制生成器维护应用业务，也不因多个应用使用相同实现而把它提升为内核合同。

具体 Provider 的命令、版本、模型、资源、环境与恢复策略由 Provider 应用管理；QQ 绑定与配置由 QQ 应用管理；浏览器登录和会话由 HTTP listener 应用管理。主仓不按应用名称注入凭据、授予权限、自动批准或暂停。普通应用通过批准版本的声明使用内核能力。

内核启动可以没有任何应用或 Provider。安装、提交、版本选择及生命周期仍要求真实身份、精确材料、审批和停止证据；删除预装组合不放宽这些合同。停服 owner CLI 可使用显式配置的 `CHRONA_MODULE_RESOURCES` 读取本地 release 输入，不接收由应用参数自授的宿主路径，也不自动生成或下载应用。

2026-11-17 本轮仅修改源码并静态核对，独立应用未提交、构建、发布或部署。旧固定输入流程和组合验收从 Git 历史查阅，不能用于证明当前版本可用。通用边界及代码地图见[架构](architecture.md)，公开目标见[API 规范](kernel-api-design.md)。
